# SurQCT
**Surrogate modeling for QCT calculations**


## Usage

To use it, run the executable file in `./surqct/` with `-h` argument for help
```
$ ./surqct -h
```

Once you have chosen the app that appears in the options from the previous command, you can run it as follows
```
$ ./surqct <app> [OPTIONS]
```
If help is needed, simply run
```
$ ./surqct <app> -h
```
