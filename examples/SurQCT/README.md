# SurQCT
**Surrogate modeling for QCT calculations**


## Usage

To use it, run the executable file `./surqct/surqct` with `-h` argument for help
```
$ ./surqct -h
```

Once you have chosen the script among the available ones resulting from the previous command, you can run it as follows
```
$ ./surqct <script-name> [OPTIONS]
```
If help is needed, simply run
```
$ ./surqct <script-name> -h
```
